AI-Based Resume Screening and Interview Analysis (Free Version)

Run:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in that folder.
4. Install packages:
   python -m pip install -r requirements.txt
5. Run:
   python -m streamlit run app.py

The interview evaluation is rule-based and runs locally. It does not require an OpenAI API key or paid API credits.
The resume matching feature uses TF-IDF and cosine similarity.
